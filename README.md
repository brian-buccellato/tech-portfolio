# Brian Buccellato Tech Portfolio Site
React + Vite site with a heavy dose of MUI.  Served from Cloudfront assets in S3, all deployments are triggered automatically via Github actions when PR's are merged to `main`.  User tracking handled by GTM and Google Analytics.

### Quickstart
For local development, run `npm run dev` and visit `localhost:5173`
